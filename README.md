# Shell Scripts

Collection of shell scripts created to automate my work while working on Linux

## apt-install.sh

Use Fuzzy Finder `fzf` to list every package inside Debian and show its content in a box using Batcat. After that you can choose the package and install it.

## apt-remove.sh

Works like **apt-install.sh** but now it lists the packages installed on my computer and remove it.
